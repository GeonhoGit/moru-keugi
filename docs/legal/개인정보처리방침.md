## 1. 요약

**모루 키우기는 개인정보를 수집하지 않습니다.**

이 앱은 네트워크 통신을 하지 않는 단일 기기 게임입니다. 계정도, 광고도, 결제도, 분석 도구도
없습니다. 게임 진행 상황은 오직 이용자의 기기 안에만 저장되며 어디로도 전송되지 않습니다.

## 2. 수집하는 개인정보

없습니다.

이름, 이메일, 전화번호, 생년월일, 위치, 연락처, 사진, 기기 식별자, 광고 식별자 중
어느 것도 수집하지 않습니다. 회원가입이나 로그인 절차 자체가 없습니다.

## 3. 기기에 저장되는 정보

게임을 이어서 하려면 진행 상황을 저장해야 합니다. 아래 정보가 **이용자 기기의 앱 전용
저장 공간**에만 보관됩니다.

| 저장 항목 | 예 |
|---|---|
| 게임 재화와 누적 기록 | 잉걸불 보유량, 평생 누적량, 타격 횟수 |
| 성장 상태 | 업그레이드 보유 수, 명인의 인장과 영구 강화 단계 |
| 진행 기록 | 완료한 주문, 달성한 업적, 해금한 외형 |
| 설정 | 효과음·배경음악 음량, 햅틱, 모션 줄이기, 숫자 표기 방식 |
| 시각 정보 | 마지막 저장 시각 (오프라인 보상 계산에 사용) |

이 정보는 개인을 식별하지 않으며, 앱을 삭제하면 함께 사라집니다.

## 4. 정보의 전송과 제3자 제공

**전송하지 않습니다.** 제3자에게 제공하거나 처리를 위탁하지 않습니다.

앱에는 광고 SDK, 분석 SDK, 크래시 리포트 도구가 포함되어 있지 않습니다.
앱의 코드에는 서버로 데이터를 보내는 통신 기능 자체가 없습니다.

## 5. 앱이 사용하는 권한

| 권한 | 사용 이유 |
|---|---|
| 진동 (`VIBRATE`) | 타격·구매·환생 시 햅틱 피드백. 설정에서 끌 수 있습니다 |
| 오디오 설정 (`MODIFY_AUDIO_SETTINGS`) | 효과음과 배경음악 재생 |
| 미디어 재생 서비스 (`FOREGROUND_SERVICE*`, `WAKE_LOCK`) | 오디오 라이브러리가 재생 세션을 관리하기 위해 요구 |
| 네트워크 (`INTERNET`, `ACCESS_NETWORK_STATE`) | 앱 개발 도구가 요구하는 항목입니다. **앱은 어떤 서버와도 통신하지 않습니다** |

마이크, 카메라, 위치, 연락처, 저장소, 다른 앱 위에 그리기 권한은 **요구하지 않습니다.**
오디오 라이브러리가 기본으로 포함하던 마이크 권한은 녹음 기능을 쓰지 않으므로 제거했습니다.

## 6. 이용자의 권리와 데이터 삭제

기기에 저장된 게임 데이터는 이용자가 언제든 직접 지울 수 있습니다.

- **앱 안에서**: 설정 → 게임 데이터 초기화 (두 번 확인 후 확인 문구 입력)
- **기기에서**: 앱 삭제, 또는 기기 설정에서 앱 저장 공간 지우기

수집하는 개인정보가 없으므로 열람·정정·처리정지 요청 대상이 되는 정보도 없습니다.
그럼에도 문의가 있으시면 아래 연락처로 알려 주시기 바랍니다.

## 7. 아동의 개인정보

이 앱은 개인정보를 수집하지 않으므로 아동으로부터도 개인정보를 수집하지 않습니다.
연령 확인 절차나 보호자 동의 절차를 두지 않는 이유도 같습니다.

## 8. 안전성 확보 조치

게임 데이터는 기기 안에만 있고 전송되지 않으므로 전송 구간의 위험이 없습니다.
저장 손상에 대비해 이중 백업과 검증 절차를 두고 있으나, 이는 개인정보 보호가 아니라
게임 진행 보존을 위한 장치입니다.

## 9. 방침의 변경

이 방침이 바뀌면 앱 업데이트와 함께 개정 내용을 알립니다.
특히 아래 기능이 추가되면 이 방침을 반드시 먼저 개정합니다.

- 계정 또는 클라우드 저장
- 광고 또는 인앱 결제
- 이용 통계 분석 도구
- 순위표 등 다른 이용자와 데이터를 주고받는 기능
